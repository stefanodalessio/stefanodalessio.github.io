A collection of websites / platforms that can be used to create web-based interactive narratives and games...

- platforms that can be repurposed for gamified adventures
	- [Google Slides](https://workspace.google.com/products/slides/)... link between slides for choose-your-own-adventure or puzzles
	- [Canva](https://www.canva.com)... usable for interactive click-through prototypes with animations
	- [MIRO](https://miro.com)... use boards, clickable links, and icons for branching or map-based adventures

- playable spaces
	- [Topia](https://topia.io/)... browser-based social world builder
	- [Spatial](https://www.spatial.io/)... create and edit 3d environments... at time of writing (2025.10.05) free tier is pretty limited... max 5 concurrent users

- game development tools for web
	- [Twine](https://twinery.org/)... designed for text based **interactive fiction** but... as it works with HTML... CSS and JS can do images... audio... video and various web-interactions... you can export and upload to [itch](https://itch.io/)
	- [Bitsy](https://ledoux.itch.io/bitsy)... simple... pixel art... room and tile based game editor... exports to HTML... can be hosted or uploaded to [itch](https://itch.io/)
		- [Bitsy Hacks](https://seansleblanc.itch.io/bitsy-hacks)... extra HTML hacks for Bitsy exports
	- [PlayCanvas](https://playcanvas.com/) HTML5 game development platform
	- [Wonderland engine](https://wonderlandengine.com/) web game development platform
